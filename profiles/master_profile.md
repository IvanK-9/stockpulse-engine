## 5. Архитектурные стандарты разработки
1. **Автономность:** Софт работает на сервере без необходимости держать включенным личный компьютер.
2. **Безопасность:** Секреты и токены API хранятся в защищенных `.env` файлах, трафик шифруется.
3. **Логирование и оповещения:** При возникновении нештатной ситуации (смена формата страницы стороннего сервиса, падение прокси) владелец получает понятное сообщение в Telegram до того, как пострадает бизнес.
4. **Прозрачность кода:** Код комментирован, структурирован, передается в Git-репозитории с инструкцией по запуску в 1 команду (`docker compose up -d`).
